# Story Library — INDEX TEMPLATE

> Copy to `config/stories.md` (gitignored) or let `/story add` create it. This is the
> index the agents scan when writing cover letters, outreach, application answers, and
> interview prep. Full story files live in `vault/Stories/` (template: `_Story Template.md`).

## How to use
Each story has `themes` and `use for` tags. When drafting or prepping, scan this index
for a matching story, then read the full vault file for specifics and metrics.
`/story find <need>` does the matching for you.
