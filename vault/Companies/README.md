# Companies

Each employer has a **folder** named after the company.

- **`<Company>.md`** — Company profile: funding, go-to-market, org, role snapshot, HQ/travel signals, employee distribution, leadership, reference links, **contacts**, and **communication log** (chronological). A **`Latest deep-dive`** callout links to [[Companies/…/Company Profiler]]. When Mark runs **Company Profiler**, he updates **this file** and **`Company Profiler.md`** in the same folder so the company tree stays complete.
- **`<Company> — <Role>.md`** — One file per job opportunity (pipeline stages, timeline, links).
- **`<Company> — Interview Prep — <Stage>.md`**, **`— Company Research.md`**, **`— Offer Analysis.md`** — Optional docs in the same folder.

Use **Navigation** sections at the top of notes for quick links in Obsidian. Company profiles and opportunity notes should include **`Profiler:`** pointing at **`[[Companies/<Company>/Company Profiler]]`** so the deep-dive sits beside the profile and roles in one folder.

See `CLAUDE.md` in the repo for agent templates.
